# VeroDate — TrueMatch Verify

Prototype demonstrativ pentru recunoașterea gesturilor cu camera. Testele: zâmbet, două degete, rotire cap. Capturi automate în memoria browserului; insignă DEMO, nu verificare de identitate.

## Pornire

```bash
npm install
npm run build
npm run dev
```

Modelele MediaPipe sunt descărcate la build în `public/models`. Nu stocați date biometrice sau chei API în repository.
